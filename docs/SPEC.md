# Transport Ship FPS — 产品规格

## 定位

**手机优先**的浏览器单地图 FPS。灵感来自穿越火线经典地图「运输船」（对称、双哨塔、地下管道绕后），
技术路线参考 Saltline（单文件、全程序化资源），但**代码与内容全部原创**。

不做：多人联机、账号系统、付费、皮肤、开箱、任何原作素材或名称。

## 一局是什么样

```
开局  选难度 → 出生点读条 2 秒 → 进图
目标  团队竞技：先到 25 杀，或 5 分钟结束按击杀数判胜
节奏  单局 3–5 分钟；死亡 3 秒后重生（无敌 1.5 秒）
对手  4 个 AI bot（同队 3 个 + 敌方 4 个，可配置）
```

## 地图：运输船（对称，约 64×40 米）

```
               敌方出生区
        ┌───┬─────────────┬───┐
        │塔 │  货柜  货柜  │塔 │   塔 = 哨塔，二层，狙击位
        ├───┴─────────────┴───┤
        │   甲板开阔区（中距对枪）   │
        │  ▣  ▣   ▣   ▣   ▣  │   货柜 = 半身高掩体，可穿不可穿各一半
        ├───┬─────────────┬───┤
        │塔 │  货柜  货柜  │塔 │
        └───┴─────────────┴───┘
               我方出生区
         两侧各有地下管道直通敌方侧翼（端到端 8 秒）
```

要素清单（M1 必须全部存在）：

1. **甲板**：平坦主战场，中央有 2 个低矮掩体（可蹲可跳）
2. **货柜群**：8 个集装箱，高 2.6 米（跳不上去，需从哨塔或箱子跳）
3. **双哨塔 ×2 侧**：有楼梯可上，二层可俯瞰中央通道，护栏半身
4. **地下管道 ×2**：从己方后场通到敌方侧翼，单行道，头顶封闭、视野受限
5. **船头船尾**：海面边界，掉出边界 2 秒内死亡（"落水"）
6. **可跳箱子**：4 处「跳箱子」点位，踩着能上货柜（CF 经典操作）

## 武器（3 把，手感区分明确）

| 武器 | 伤害 | 射速 | 弹匣 | 特点 |
|---|---|---|---|---|
| 突击步枪 M4 类 | 24 | 700 rpm | 30 | 中距离主力，连发后坐力上抬 |
| 狙击枪 | 95（爆头必杀） | 45 rpm | 5 | 开镜视野收窄，命中判定严格 |
| 霰弹枪 | 12×8 弹丸 | 60 rpm | 6 | 5 米内致命，10 米外几乎无效 |

共同规则：爆头 ×2 伤害；后坐力按「首发精准 + 连发扩散」；换弹期间不可开火；
弹药无限但需换弹（保留战术节奏，不做拾取）。

## 移动

```
走 4.2 m/s · 跑 6.0 m/s（手机默认按住「跑」） · 蹲 1.9 m/s（命中体积减半）
跳 初速 4.8 m/s（可蹲跳，空中不可射击）
受击：屏幕边缘红晕 + 抖动 + 击中方向指示
```

## 移动端操作（验收基准，不是"顺便支持"）

```
左半屏        虚拟摇杆（半径 56 CSS px，死区 8px）
右半屏        拖动转视角（灵敏度可调，默认 0.35°/px）
右下          开火键（半径 40px）· 换弹键 · 换枪键
左下上方      「跑」·「蹲」·「跳」
顶部          血量 · 弹药 · 击杀比分 · 计时
自动瞄准      只在 8° 锥内轻微吸附（可关），不自动开火
```

硬指标：
- 所有可点元素 ≥ 44×44 CSS px（摇杆/按钮实际热区 ≥ 56）
- 目标 60fps；掉到 45fps 以下自动降分辨率（DPR 1.5 → 1.0）
- 支持横屏与竖屏（竖屏时提示旋转，但**不阻断**：竖屏也能完整玩）
- 页面不可滚动、不可缩放（`touch-action: none`、锁定 viewport）

## AI（bot）

三档：`recruit`（反应 600ms，命中率 35%）、`veteran`（350ms，55%）、`elite`（200ms，72%）。
行为：巡逻 → 发现（视锥 90° / 视距 30m / 遮挡检测）→ 交火（点射 + 侧移）→ 残血撤退 →
队友报点（一个 bot 发现玩家，同队 3 秒内向该点靠拢）。

## 技术约束

- 运行时依赖只有 `three`；构建用 `vite`；语言 `typescript` strict。
- **零外部素材**：几何用内置 primitive 组合，贴图用 canvas 程序化生成，音效用 WebAudio 合成。
- 游戏逻辑与渲染分离：`src/game/**` 不许 import DOM / three（可用 `node --test` 单测），
  `src/render/**` 才碰 three 与 canvas。
- 构建产物目标：单页 + 单 JS bundle，gzip 后 < 1.2 MB。
- 不用后处理重效果（手机 GPU 有限），阴影只开一张方向光 shadow map（1024）。
- 帧预算：单帧 CPU 逻辑 ≤ 3ms，draw call ≤ 120。

## 里程碑

- **M1 可玩骨架**：地图 blockout（甲板/货柜/哨塔/管道/边界）+ 第一人称移动跳跃蹲 +
  一把步枪射击命中 + 手机双摇杆操作 + HUD 血量弹药。
- **M2 战斗闭环**：三把武器 + 换弹 + 后坐力 + 4 bot AI + 击杀/重生/比分 + 胜负结算。
- **M3 观感**：程序化贴图（码头金属、集装箱锈迹、海面）、光照阴影、开火火花/弹壳/命中血雾、
  脚步与枪声音效、受击反馈。
- **M4 打磨**：手机性能档位自适应、准星与命中提示、小地图、设置项（灵敏度/画质/静音）、
  单文件打包（dist 内联成一个 html）。

## 明确不做

- 多人联机 / 房间 / 匹配
- 任何《穿越火线》《CS》原作素材、地图几何复刻、枪械名、UI 素材
- 账号、存档云同步、内购
