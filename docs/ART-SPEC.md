# ART-SPEC — 运输船 FPS（视觉与声音，强制）

> 所有自动化轮次只要动 `src/render/**`、`src/audio/**`、`index.html`，必须先读本文件。

## 0. 硬红线

1. **零外部素材**：不许引入任何图片/模型/音频文件，不许 CDN 字体或图标。全部程序化。
2. **不抄原作**：不许使用《穿越火线》《CS》的任何素材、枪械名（用 M4 类/狙击枪/霰弹枪这类通称）、
   地图几何复刻、UI 元素截图、配色数值。参考只限技术思路。
3. **手机可读性优先于画面华丽**：任何特效如果让 390px 宽屏幕上的敌人更难辨认，一律不做。

## 1. 配色（运输船：冷工业 + 警示色）

程序化材质统一从这个调色板取色，禁止在渲染代码里散落字面量（集中在 `src/render/palette.ts`）。

```ts
export const PALETTE = {
  deck:        ['#2b3138', '#3a424b', '#4a535e'],  // 甲板钢板：暗/中/亮 3 档
  deckLine:    '#c9a227',                            // 甲板警示黄线
  container:   ['#7a3b2e', '#2f5d50', '#41506b', '#6b5a3e'], // 集装箱 4 种主色（红/绿蓝/蓝灰/土黄）
  containerTop:'#8a8a8a',
  rust:        '#6b3a22',
  tower:       ['#39424d', '#4b5561'],
  pipe:        '#20262c',
  sea:         ['#13212b', '#1b2f3c', '#27414f'],
  sky:         ['#0e1620', '#1a2a38'],
  fog:         '#16222c',
  teamA:       '#4fa4f1',   // 我方：蓝
  teamB:       '#d9534f',   // 敌方：红
  hpFull:      '#5fd35f', hpMid: '#e0c341', hpLow: '#d9534f',
  uiPanel:     'rgba(12,18,24,0.78)',
  uiBorder:    '#3f5666',
  uiText:      '#dfe7ee', uiDim: '#8fa0ad',
  accent:      '#ff8b3d',   // 开火/命中/危险提示

```

规则：
- 每个材质 3 档明暗，**档间同时改明度与色相偏移**（暗部偏蓝、亮部偏白），禁止单纯加减亮度。
- 敌我识别只能靠**轮廓 + 颜色**双重区分：我方蓝、敌方红，且敌人肩部有一圈高位色标记（手机上看不清颜色时靠形状补）。

## 2. 程序化贴图规范

| 表面 | 生成方式 | 分辨率 |
|---|---|---|
| 甲板钢板 | 基础灰 + 接缝线（1px 暗线网格）+ 多尺度噪声划痕 + 边缘锈斑 | 512×512，重复平铺 |
| 集装箱 | 竖条波纹（正弦明暗）+ 主色 + 顶部暗带 + 边角锈 | 256×256 |
| 塔身/护栏 | 纯色 + 细噪点 + 底部积尘渐变 | 256×256 |
| 海面 | 两层滚动法线噪声 + 菲涅尔近似 + 反射天空色 | 运行时着色器 |
| 天空 | 垂直渐变 + 低云噪声（可选） | 着色器 |

约束：
- 贴图生成一次，缓存到 `Map<string, THREE.Texture>`，**不许每帧生成**。
- 不在手机上超过 512×512 的 canvas 生成（首次加载卡顿）。
- `texture.anisotropy = min(4, renderer.capabilities.getMaxAnisotropy())`。

## 3. 可读性硬指标（390×844 验收）

1. **100ms 内可区分**：敌人 / 队友 / 掩体 / 可交互物，四类在形状或色相上必须不同。
2. 敌人在 20 米外仍能看清头部轮廓（头顶 4px 高的红色标记带）。
3. 所有触屏控件热区 ≥ 56×56 CSS px，图标本体 ≥ 40px，间距 ≥ 8px。
4. 准星：4 条离散线段 + 中心点，扩散随移动/射击变化，颜色对比度足够（白 + 黑描边）。
5. 受击反馈三件套：屏幕边缘红晕（120ms）、轻微镜头抖动（幅度 ≤ 2px）、方向指示弧。
6. 血量 ≤ 30% 时屏幕边缘持续脉动（周期 1.2s，透明度 ≤ 0.25）。

## 4. 声音（WebAudio 程序化，零文件）

| 事件 | 合成方式 | 时长 |
|---|---|---|
| 步枪射击 | 白噪 burst + 1200Hz 低通扫频 + 快速衰减 | ≤120ms |
| 狙击 | 低频冲击（80Hz）+ 长尾噪声 | ≤400ms |
| 霰弹 | 双 burst + 更宽频带 | ≤200ms |
| 换弹（弹匣入位） | 两次短金属点击（方波 1.6k/2.2k） | ≤150ms |
| 命中敌人 | 高频 ping（1.8k）+ 短噪声 | ≤80ms |
| 自身受击 | 低频 thud + 噪声 | ≤150ms |
| 脚步 | 滤波噪声，随速度调间隔 | ≤60ms |
| 击杀提示 | 两音上行 | ≤200ms |

- 必须由首次手势 `AudioContext.resume()` 解锁。
- 同类并发 ≤ 6，超出丢弃最旧。
- 距离衰减：3D 声源在 25 米外不可闻。
- 设置里「静音」即时生效并持久化。

## 5. 性能红线（手机）

```
draw call        ≤ 120（同类几何用 InstancedMesh：货柜/箱子/护栏）
单帧逻辑 CPU     ≤ 3ms
阴影             只有一盏方向光投影，map 1024，静态物体用 baked 阴影贴图或简单暗面
后处理            禁止（不用 bloom/SSAO/抗锯齿以外的东西）
DPR               上限 2；掉到 45fps 以下自动降到 1.25 / 1.0
每帧对象分配      0（预分配池：弹壳、火花、伤害数字）
```

## 6. "好玩"的可验证标准（每轮自检）

1. 打开 3 秒内知道自己该往哪走（有方向提示或明显的地标）。
2. 开枪有后坐力、枪口火光、枪声、命中提示——四样缺一不可。
3. 被打时知道子弹从哪来（方向指示），能在 0.5 秒内转身对枪。
4. 手机上单手能完成"移动 + 开火"，双手能完成"跑 + 转视角 + 换弹"而不误触。
